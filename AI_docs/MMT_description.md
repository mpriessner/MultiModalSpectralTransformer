## File and Folder Breakdown

It's important to note that a `models` folder exists at the root of the repository (`/MultiModalSpectralTransformer/models`). This folder contains the trained model files for the different components, including the MMT. These model files are not included in this repository clone due to their large size. The MMT-related models are located within the `models/mmst` subdirectory.
