# ChemPropIR Documentation

This section describes the files and folders related to the ChemPropIR functionality within this repository.

## Files and Folders:

It's important to note that there is a 'models' folder at the root of the repository (`/MultiModalSpectralTransformer/models`). This folder contains the trained model files, which are not included in this repository clone due to their size. The models specifically related to ChemProp-IR are located within `models/chemprop-ir`.



*   **3.0_Chemprop_IR_Data_Generation_.ipynb**: Jupyter notebook for generating data for the ChemProp IR model.
*   **utils_MMT/ir_config_V8.json**: Configuration file specifically for the IR simulation and potentially the ChemPropIR model.
*   **utils_MMT/ir_simulation_v15_4.py**: Python script containing functions for simulating IR spectra. This is likely used to generate data for ChemPropIR or for evaluating its performance.
*   **(Potentially other files within `scripts/` or other directories with "chemprop" or "ir" in the name)**: There may be additional scripts or utility files used for training, evaluating, or running the ChemPropIR model. These would need to be identified based on their names and content.
