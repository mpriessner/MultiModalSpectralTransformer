This section describes the files related to the SGNN (Spectral Graph Neural Network) functionality within the repository.

*   `utils_MMT/sgnn_code_pl_v15_4.py`: This file likely contains the implementation of the SGNN model, potentially using PyTorch Lightning (`pl`) for training and related functionalities.
